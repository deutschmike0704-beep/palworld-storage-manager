# 0.1.0 — 2026-07-25

First code-complete build (v1 feature set per FEATURE_SPEC_v1).

## Added

- Bootstrap: modular Scripts layout (config/util/core/features/hooks),
  leveled logging, deep-merged user config (`Scripts/config/user.lua` or
  `<mod root>/config/config.lua`), fail-soft everywhere.
- **F2 unlimited weight in base**: return-value override on the max-weight
  query while the player stands in their own base camp; automatic vanilla
  restore on leave; poll-driven inside/outside state; strict-ownership mode
  for multiplayer (`weight.assume_own_base_when_unverified=false`).
- **F1 unified craft storage** (code-complete, runtime-gated): storage index
  across all containers of the current base + player inventory, live-read
  counting, deterministic cross-container consume with pre-check, removal
  verification and best-effort rollback; double-consume prevention via
  `consume_mode = "vanilla_fallback"` (consume only when vanilla observably
  failed). **Soft-disabled by default** until the 1.0 craft hook paths are
  verified (`api.craft.count_hook/consume_hook`, see
  research/notes/verified-hooks.md).
- In-game API discovery dump (F6 / `debug.dump_apis_on_init`) to generate
  verification data; log-only index summary mode (`debug.log_index_summary`).
- Tooling: `tools/deploy/deploy.ps1` (Game Pass/WinGDK, layout
  auto-detection), `tools/packaging/package.sh` (release zip).
- Offline test suite (`lua tests/scripts/run_all.lua`): 27 tests covering
  bootstrap fail-soft, F2 state machine, index/count/consume semantics and
  double-consume prevention.

## Known limitations

- F1 inactive out of the box (hook paths unverified — by design, no guessed
  engine paths). Verification workflow: docs/guides/TESTING_GAMEPASS.md §3.
- F2 depends on `PalPlayerInventoryData:GetMaxInventoryWeight` resolving on
  1.0; if not, it disables itself with a clear log line.
- Multiplayer: local-player logic only; dedicated servers need the mod
  server-side for F1 (spec §6.7).
